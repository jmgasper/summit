# Summit artwork

The editable SVGs are the artwork supplied in
[issue #39](https://github.com/jmgasper/summit/issues/39), with the lock from
[issue #41](https://github.com/jmgasper/summit/issues/41).

`python3 tools/render-toolbar-icons.py` (CairoSVG required) renders the checked-in
24, 48 and 96 pixel toolbar PNGs. The forward arrow rotates the back artwork
180 degrees. The Translation Kit loads these resources; BControl generates
pressed and disabled states. A green check distinguishes a saved bookmark.

`resources/Summit.hvif` is the native vector tracing of the mountain and flag,
generated by `python3 tools/make-summit-icon.py` from the original drawing's
geometry. The matching original drawing is `docs/summit-icon.png`; `app.svg`
is the supplied editable SVG tracing. The app and Deskbar launcher both use
the HVIF resource.
