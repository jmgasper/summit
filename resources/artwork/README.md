# Summit artwork

The toolbar uses Font Awesome Free 6.7.2 silhouettes, with sources and
attribution in [fontawesome](fontawesome/README.md). Navigation, Home,
Downloads, bookmark states, overflow, certificate states and Reader mode
share a 20-point canvas with per-glyph optical sizing. Saved bookmarks use
a filled gold star; certificate warnings use an amber warning triangle.

Regenerate the checked-in native vectors with:

```sh
python3 -m pip install fonttools
python3 tools/make-toolbar-icons.py
```

Haiku renders the vectors at the actual display density. `Chrome.cpp` tints
their alpha masks using theme colors, including disabled and private states,
and preserves the padded canvas rather than stretching every silhouette to
the same bounds. There is no runtime font or SVG dependency.

`tools/render-toolbar-icons.py --output /tmp/toolbar-icons.png` produces a
contact sheet from the same SVG sources and optical sizes (CairoSVG and Pillow
required). Verify the native rendering in the app after changing geometry.

The older editable SVGs in this directory are the artwork supplied in
[issue #39](https://github.com/jmgasper/summit/issues/39), with the lock from
[issue #41](https://github.com/jmgasper/summit/issues/41), retained as references.
They are no longer embedded in the toolbar.

`resources/Summit.hvif` is the native vector tracing of the mountain and flag,
generated by `python3 tools/make-summit-icon.py` from the original drawing's
geometry. The matching original drawing is `docs/summit-icon.png`; `app.svg`
is the supplied editable SVG tracing. The app and Deskbar launcher both use
the HVIF resource.
