# Toolbar icon refresh — 9 October 2026

Installed on the X399 as `bundle-7a0yiobd` using the existing `SkiaCGMiPGO`
engine and `prefix-20261002` Mesa configuration. The Desktop launcher,
`Summit-installed` link and Deskbar application entry resolve to this build.
Summit was restarted cleanly and both existing tabs were restored in order.
The old launcher is backed up at
`/boot/home/summit/launcher-backups/Summit-current.pre-20261009-1405.sh`.

The mixed raster artwork and older toolbar vectors are replaced by 15
Font Awesome native vector resources. A common 20-point canvas preserves
optical sizes; colors follow the theme and button state. Filled bookmarks,
certificate warnings and active Reader mode have gold, amber and green
accents. Runtime rendering needs neither an icon font nor an SVG translator.
Font Awesome attribution and license files ship in the bundle.

Validation on the X399:

- Native build, link, resource compilation and bundle hash verification passed.
- All 15 HVIFs regenerated byte-for-byte from the pinned SVGs.
- Haiku rendered every vector at 20, 40, 60 and 80 pixels. Comparison with the
  SVG alpha masks gave 98.59–99.84% overlap; visual review confirmed open
  counters, smooth curves and unclipped edges.
- The actual `ToolButton` implementation was inspected at 200% display density
  in Haiku and flat appearances, normal and private colors, with enabled,
  disabled and pressed states.
- In the browser, Start Page and HTTPS loading, back/forward navigation,
  the certificate lock, Reader button, adding a bookmark (filled star),
  and a private window passed the visual and functional smoke check.
- The installed process responded to `summitctl`, restored both user tabs,
  and successfully loaded the selected page. The installed binary hash and
  source manifest were checked against the new bundle.
