How long WebAssembly takes to start, and where

Each case runs for seconds (default 3) in a dedicated worker and on the page's main thread: asynchronous compilation alone, asynchronous instantiation of a module without memory and of one with a 64 KiB memory, and the synchronous constructors. The page meanwhile counts how long its own main thread goes without running a 10 ms interval. GitHub issue #6: an instantiation in a worker took about 130 ms in Summit and 2 ms in Firefox.
