A page that stops answering

Half a second after it loads, this page runs a script that never ends, so its web process answers nothing more: not the request to close the tab, not the browser's quit. Closing the tab, the window or the browser must still work. Summit waits ten seconds for the page to approve closing, checks that its process answers nothing at all, and then closes the page and ends the process (docs/STATUS.md, 1 October 2026).
