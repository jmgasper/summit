Does the page keep drawing?

A counter changes on every animation frame for seconds (30), and the page counts its frames each second. A page whose compositor has stalled gets no frames at all; Summit's stall recovery (docs/STATUS.md, 1 October 2026) should bring them back within a few seconds. With SUMMIT_TEST_COMPOSITOR_STALL=late, timer or frame one stall is made on purpose. The result is posted to the bench server; it needs no input, so it can run beside someone at work.
