Key derivation as a password manager does it

GitHub issue #7: 1Password spins after the password is entered. Its unlock derives keys with PBKDF2-HMAC-SHA256 (650,000 iterations) and decrypts in WebAssembly. This times the same derivation three ways: compiled to WebAssembly (from tools/bench/pages/crypto-speed.c, built with clang --target=wasm32 -O2 -nostdlib -c) on the page and in a worker, and with WebCrypto's deriveBits.
